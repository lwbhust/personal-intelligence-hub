# PIH 用户指南

本指南对应 Phase 8 的五入口界面。PIH 的目标是让你每天只做一件事：打开「今日」，看少量真正值得关注的信息。

---

## 1. 首次使用

1. 打开应用，等待左下角显示「运行正常」。
2. 进入「设置 → 信息源管理」，添加 RSS/Atom 来源。
3. 进入「设置 → 自动化设置」，确认「自动分析新文章」已开启。
4. 等待采集与自动处理完成，回到「今日」。

不需要手动启动采集任务或 AI，也不需要在日常使用中查看任务 ID、队列或租约。

---

## 2. 今日

「今日」回答一个问题：今天有哪些信息真正值得我关注？

- **概览**：今日新增、值得关注、重点事件、待阅读。
- **今日精选**：3–5 条按兴趣、事件重要性与时效排序的内容，展示推荐理由与来源。
- **重点事件**：只展示至少 2 篇报道的事件；同一事件不会在精选和事件区重复出现。
- **待阅读**：尚未阅读且值得关注的文章。
- **最近阅读**：继续上次读到的内容。
- **自动化状态**：关闭、暂停或失败时，顶部会出现一键启用/恢复/查看入口。

每条内容支持：打开阅读、稍后阅读、感兴趣、不感兴趣；反馈会立即影响推荐。

---

## 3. 阅读

顶部六个视图：

| 视图 | 说明 |
|---|---|
| 推荐 | 后端推荐结果，已排除已读、已稍后阅读与负反馈内容 |
| 全部 | 全部有效文章 |
| 稍后阅读 | 你保存稍后读的文章；不会改变兴趣权重 |
| 收藏 | 收藏会轻微提升相关推荐 |
| 历史 | 已读文章 |
| 搜索 | 本地全文检索 |

### 搜索与筛选

- 检索范围：标题、摘要、已抓取的正文；
- 支持来源、发布时间（近 24 小时 / 7 天 / 30 天）、阅读状态、仅收藏；
- 顶部显示真实结果总数与当前筛选摘要；
- 点击「清空条件」恢复全部状态；
- 无结果时会说明原因并提供重置入口。

### 阅读器

- 保留完整排版、字号切换与阅读进度；
- 「仅摘要」文章可以点击「抓取全文」，失败时保留摘要并说明原因；
- 收藏、已读、稍后阅读与兴趣反馈都在阅读器工具栏。

---

## 4. 事件

- 默认查看近 7 天事件；
- 事件由 Pipeline 自动聚合，不需要手动点击聚类；
- 事件详情包含时间线、关联文章、实体、评分与人工校正；
- 「维护」菜单仅用于异常时手动增量聚类或重算评分；
- 单篇文章不会在首页被包装成「重点事件」。

---

## 5. 洞察

- **概览**：文章/来源/事件统计、趋势、来源分布、热点事件；
- **情报报告**：本地 AI 生成的日报/周报，保留引用来源与历史版本；
- 所有统计来自本地 SQLite，不使用静态示例数据。

---

## 6. 设置

| 分区 | 用途 |
|---|---|
| 兴趣偏好 | 每日阅读预算；按核心/延伸/一般/暂不关注调整关注领域；采纳或忽略系统学习建议；恢复被屏蔽来源 |
| 信息源管理 | 添加、编辑、停用来源；立即采集；查看健康日志 |
| 自动化设置 | 自动分析开关、暂停/恢复、等待/完成/失败计数、补齐历史积压 |
| 采集健康 | 正常 / 偶发异常 / 持续失败 / 暂无数据；错误原因与单源重试 |
| 存储与备份 | 数据库状态、Schema 版本、备份机制说明 |
| 高级诊断 | AI 分析、自动化管道明细、采集任务、文章高级筛选、分类、运行状态 |

普通使用不需要进入高级诊断。

---

## 7. 数据与隐私

- 所有数据保存在 `~/Library/Application Support/PersonalIntelligenceHub/`；
- Sidecar 仅监听 `127.0.0.1`，每次启动使用随机端口与随机 Token；
- 默认不使用云端模型，任何 `*-cloud` 模型都会被阻断；
- 数据库迁移只新增，不重建或覆盖用户数据库。

---

## 8. 常见问题

**本地服务未就绪**
检查应用是否完整启动；可在「设置 → 高级诊断 → 运行状态」查看 Sidecar 状态与错误摘要。

**Ollama 不可用**
采集与阅读仍可正常工作；AI 任务会标记失败或等待，模型恢复后可重试。

**某个来源持续失败**
在「设置 → 采集健康」查看错误原因。单次 DNS 失败不代表来源永久失效；403/404 等持续错误可考虑停用来源。

**搜索没有结果**
尝试更短的关键词，或清空来源、时间、阅读状态与收藏筛选。正文搜索只覆盖已抓取的正文。
