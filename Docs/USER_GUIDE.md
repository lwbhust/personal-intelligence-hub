# Phase 7.3.1 — 使用指南（为我筛选 / 兴趣画像 / 每日精选）

> App 版本 `0.11.0`｜入口：侧边栏「工作台 → 为我筛选」

## 1. 首次使用

1. 启动 App，默认进入「为我筛选」。
2. 点击「兴趣画像」或引导卡上的「配置兴趣画像」。
3. 添加 1–3 个核心关注：
   - 领域类：选择“领域/主题”（例如 科技/财经/国际）并设为“核心关注”；
   - 主题类：选择“技术主题”（如 人工智能）并填写关键词（AI、Agent、大模型）；
   - 关键词类：只靠关键词匹配时分数会被标注“仅关键词命中”，不会给满权重。
4. 可选：为兴趣关联已有实体（搜索后点击“关联”），或关联信息源。
5. 保存后回到首页，点击「刷新」。

## 2. 首页怎么读

- **顶部指标**：今日采集、今日精选预算、重点事件、必读数量。全部来自真实数据库。
- **推荐卡片**：
  - 左侧标签：必读 / 推荐 / 观察 / 低优先级；事件或文章；重大事件兜底。
  - 分数：0–100，代表推荐优先级，**不代表事实真实性**。
  - 推荐理由：命中核心兴趣、包含新信息、刚刚发布、事件重要性较高等。
  - 说明：来源质量未知、事件重要性未知等中性处理会明确标注。
  - 「评分依据」：展开五维分数与权重。
- **折叠区**：观察 / 低优先级 / 其他信息默认折叠，内容不会被删除。

## 3. 反馈

在推荐卡片或文章详情点击「反馈」：

| 选项 | 效果 |
|---|---|
| 感兴趣 | 稍加分；连续 3 次可在画像页看到“提高权重”建议 |
| 非常重要 | 明显加分，可把高质量条目提升为必读 |
| 不感兴趣 | 降权；连续 3 次可看到“降低权重”建议 |
| 重复内容 | 降低新颖性，减少重复占位 |
| 不喜欢来源 | 降低该来源内容分数；可在画像页彻底屏蔽来源 |
| 暂不处理 | 仅记录，不改分 |

可随时「撤销反馈」。反馈历史保留，但撤销后不再影响评分。

## 4. 兴趣变化建议

- 画像页「系统观察到的兴趣变化」只做提示，**不会自动修改**你的兴趣或权重。
- 点击「应用」才会写入；也可以忽略。
- 关闭“允许生成兴趣调整建议”后不再展示新建议（已有建议不自动应用）。

## 5. 阅读预算

- 每日条数：1–100；每日分钟：1–600（按每条约 4 分钟折算）。
- 同时设置时取更严格者；预算只限制首选推荐数量，不影响其他文章查看与搜索。

## 6. 每日精选

- 入口：首页右上「今日精选」。
- 内容：今日不容错过、今日重点、核心兴趣动态、重要事件变化、新兴主题、独立线索。
- 「重新生成」会保留历史版本（旧版本标记为 superseded）。
- 本版本为规则生成，不调用 AI；界面会明确标注“规则生成”。

## 7. 屏蔽来源 / 隐私

- 画像页可取消屏蔽；屏蔽只影响推荐，不影响文章列表与搜索。
- 「隐私与数据」：
  - 清除全部反馈记录；
  - 重置兴趣画像与推荐（删除兴趣、反馈、日报、推荐结果，不删除文章/事件/分析）。
- 所有个人数据仅保存在本机 `~/Library/Application Support/PersonalIntelligenceHub/pih.sqlite3`。

## 8. 已知限制

- 来源可信度尚未配置时，来源维度按中性 50 分处理，并在卡片上标注。
- 当前事件评分整体偏低，未反馈时较难达到“必读”（≥85）；标记“非常重要”或在画像 `scoring_config` 中调低阈值即可。
- 单成员事件较多；事件卡片只展示真实文章数与来源数，不宣称多来源证实。
- 日报暂不提供 AI 概览；历史日期按当前数据生成，不代表当时快照。
